# Julia implementation

| | |
|---|---|
| Package | `POPSRegression.jl` |
| Style | Julia and StatsAPI conventions |
| Repository | [`POPS-UQ/POPSRegression.jl`](https://github.com/POPS-UQ/POPSRegression.jl) |
| Documentation | [`/POPSRegression.jl/`](https://pops-uq.github.io/POPSRegression.jl/) |

The package provides the Julia implementation and maintains its generated
[API reference](https://pops-uq.github.io/POPSRegression.jl/api/). Its
Documenter site also contains scientific workflows for
[ACE fitting](https://pops-uq.github.io/POPSRegression.jl/ace/) and
[molecular dynamics](https://pops-uq.github.io/POPSRegression.jl/md/).

The Julia package has its own versions, releases, dependencies, and CI. Julia
interfaces remain idiomatic rather than mirroring Python syntax.
