# Python implementation

| | |
|---|---|
| Package | `popsregression` |
| Style | scikit-learn compatible |

The package provides the Python estimator and its fitting, prediction, and
uncertainty interfaces. Its generated
[API reference](https://pops-uq.github.io/popsregression/api/) and
[worked example](https://pops-uq.github.io/popsregression/example/) are the
authoritative implementation documentation.

The Python package has its own versions, releases, dependencies, and CI. Shared
method documentation belongs on this central site; Python-specific pipelines,
examples, and API details belong in the package repository.
